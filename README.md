# Fake News Detection using NLP and Machine Learning

This project focuses on detecting fake news using Natural Language Processing (NLP) techniques and machine learning models. The model is trained on a dataset of fake and real news headlines/articles and aims to classify whether a news item is genuine or not.

## 🔍 Project Overview

The notebook demonstrates:
- Text preprocessing and cleaning
- Vectorization using TF-IDF
- Model training using PassiveAggressiveClassifier
- Evaluation using accuracy score and confusion matrix

## 📁 Files

- `fake news detection.ipynb`: Main Jupyter Notebook containing the code and output
- `requirements.txt`: Python dependencies
- `README.md`: Project overview and instructions
